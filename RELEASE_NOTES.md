# FrameLab v0.1.0

Initial research portfolio release with:
- MovieLens 100K download and globally chronological warm-start evaluation.
- PyTorch two-tower model and a Transformers genre encoder trained from scratch.
- Recall@10, NDCG@10 and binary rating-label normalized entropy.
- Three bounded LangGraph training-data interventions and a fixed baseline gate.
- Paired-seed replication, no-content ablation and training-cost accounting.
- Optional PySpark validation/Parquet ingestion and Optuna exploration.
- MLflow tracking, measured reports, synthetic-fixture tests and GitHub Actions.

This release is a reproducible movie-recommendation proxy study, not a
production video recommender or a claim of guaranteed self-improvement.
